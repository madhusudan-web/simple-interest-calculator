# Simple Interest Calculator

## Description

The Simple Interest Calculator is a basic project that calculates simple interest based on the principal amount, annual interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Example

* Principal: 1000
* Rate of Interest: 5%
* Time: 2 years
* Simple Interest: 100

## Technologies Used

* Basic programming concepts
* Arithmetic operations

## How It Works

1. Enter the principal amount.
2. Enter the annual interest rate.
3. Enter the time period in years.
4. Calculate simple interest using the formula.
5. Display the calculated interest.

## Output

For a principal of 1000, an interest rate of 5%, and a period of 2 years, the simple interest is 100.
